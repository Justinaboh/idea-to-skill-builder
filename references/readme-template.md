# README Template (Stage 7)

The README is a public product page for people discovering the skill on GitHub. It is not the AI's instructions. Someone should understand the project without opening SKILL.md.

Required sections, in order:

1. **Title and one-line pitch**
2. **What it is**: two or three sentences
3. **The problem it solves**
4. **Why it is useful**: concrete outcomes
5. **What it can do**: a short capability list
6. **How it works**: the stages or process in plain words
7. **Who it is for**
8. **What makes it different**: only true, checkable differences
9. **Installation and use**: step by step, per supported platform; link to the platform's own current documentation rather than guessing its steps
10. **Supported platforms**: list only what you verified; mark the rest "should work, unverified"
11. **Repository contents**: file tree with one line each
12. **Example prompts**: 4-6 realistic prompts
13. **Known limitations**
14. **Contributing**: how to report issues and propose changes
15. **Licence**

Rules: no unsupported compatibility claims, no screenshots or badges that do not exist, no marketing filler, no private information.
